# State-by-State Tax Research Accessibility Analysis

**Created:** January 10, 2026
**Purpose:** Categorize states by ease of obtaining property tax information for loan underwriting

---

## Accessibility Scoring Criteria

| Factor | Weight | Description |
|--------|--------|-------------|
| **Online Access** | 30% | Is tax data available online? |
| **Centralization** | 25% | Statewide portal vs fragmented by county/town |
| **Cost** | 20% | Free vs subscription/per-search fees |
| **Search Flexibility** | 15% | Address, owner, parcel ID search options |
| **Data Completeness** | 10% | Delinquent status, sale dates, assessed values |

## Special Considerations by State

### Florida (Tier 1)
```
✅ All 67 counties have Property Appraiser websites
✅ Most use similar software (PACS, Aumentum)
✅ Free access to assessed values, exemptions, sales history
✅ Tax Collector sites show delinquent status
✅ Easy address and owner name search
```

### Texas (Tier 1)
```
✅ Central Appraisal Districts (CAD) for each county
✅ Most have excellent online portals
✅ Tax assessor-collector separate but linked
✅ Protest values, exemptions visible
⚠️ Some rural counties less developed
```

### California (Tier 2)
```
✅ Large counties (LA, Orange, SD) have good portals
⚠️ 58 counties with varying systems
⚠️ Prop 13 makes values less intuitive
⚠️ Some counties charge for detailed reports
⚠️ Supplemental taxes complicate research
```

### New York (Tier 3)
```
❌ NYC: Multiple agencies (DOF, ACRIS, HPD)
❌ Upstate: 932 towns + 62 cities each assess
⚠️ Some counties have consolidated assessment
⚠️ ORPS provides some statewide data
❌ Very time-consuming outside NYC
```

### Pennsylvania (Tier 3)
```
❌ 2,560 municipalities
❌ Some counties do assessment, others don't
⚠️ Allegheny, Philadelphia have good portals
❌ Many townships have minimal online presence
❌ Must identify school district for tax bills
```

### New Jersey (Tier 3)
```
❌ 564 municipalities
⚠️ NJ Tax List Search provides some data
⚠️ Each town has own tax collector
⚠️ Revaluation cycles vary by municipality
❌ Must check municipal AND county
```

### Connecticut (Tier 3)
```
❌ 169 towns, no county government
⚠️ Vision Government Solutions covers many towns
⚠️ Each town sets own mill rate
❌ Must find correct town assessor website
❌ Grand List dates vary
```

### Massachusetts (Tier 3)
```
❌ 351 municipalities
⚠️ Patriot Properties covers many
⚠️ State DOR has some aggregate data
❌ Each city/town has own assessor
⚠️ Fiscal year starts July 1 (confusing)
```

## Recommended Research Workflow by Tier

### Tier 1 States
```
1. Go directly to County Assessor/Property Appraiser website
2. Search by address or owner name
3. Note parcel ID for tax collector lookup
4. Check tax collector site for delinquent status
5. Done in 5-10 minutes per property
```

### Tier 2 States
```
1. Identify the county
2. Find county assessor website (Google "[County] [State] property search")
3. May need to check separate tax collector site
4. Some states: try third-party aggregators (Beacon, Vision)
5. 10-20 minutes per property
```

### Tier 3 States (Town-Level)
```
1. Identify TOWN, not just county (critical step)
2. Google "[Town] [State] tax assessor" or "property search"
3. If no website, may need to call town hall
4. Check for Vision, Patriot Properties, or similar vendor
5. 20-45 minutes per property, may require phone calls
```

## Database Schema Recommendation

Based on this analysis, the schema should include:

```sql
-- States with tax accessibility metadata
CREATE TABLE states (
    id SERIAL PRIMARY KEY,
    code CHAR(2) UNIQUE NOT NULL,
    name VARCHAR(100) NOT NULL,
    fips_code CHAR(2),

    -- Tax research metadata
    tax_level VARCHAR(20) NOT NULL, -- 'county', 'municipal', 'mixed'
    accessibility_tier INTEGER CHECK (accessibility_tier BETWEEN 1 AND 4),
    research_notes TEXT,
    avg_research_time_minutes INTEGER,
    statewide_portal_url VARCHAR(500),

    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Counties (always needed for geographic reference)
CREATE TABLE counties (
    id SERIAL PRIMARY KEY,
    state_id INTEGER REFERENCES states(id),
    name VARCHAR(100) NOT NULL,
    fips_code CHAR(5),

    -- Only used if state.tax_level = 'county'
    assessor_url VARCHAR(500),
    tax_collector_url VARCHAR(500),
    gis_url VARCHAR(500),
    recorder_url VARCHAR(500),
    phone VARCHAR(50),

    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(state_id, name)
);

-- Municipalities (for town-tax states)
CREATE TABLE municipalities (
    id SERIAL PRIMARY KEY,
    state_id INTEGER REFERENCES states(id),
    county_id INTEGER REFERENCES counties(id), -- NULL for NE states
    name VARCHAR(100) NOT NULL,
    type VARCHAR(50), -- 'town', 'city', 'township', 'borough', 'village'

    -- Tax research URLs
    assessor_url VARCHAR(500),
    tax_collector_url VARCHAR(500),
    gis_url VARCHAR(500),
    phone VARCHAR(50),

    -- Research metadata
    online_access BOOLEAN DEFAULT true,
    notes TEXT,

    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(state_id, county_id, name)
);

-- Unified view for tax jurisdiction lookup
CREATE VIEW tax_jurisdictions AS
SELECT
    s.code as state_code,
    s.name as state_name,
    s.tax_level,
    s.accessibility_tier,
    CASE
        WHEN s.tax_level = 'county' THEN c.name
        ELSE m.name
    END as jurisdiction_name,
    CASE
        WHEN s.tax_level = 'county' THEN 'county'
        ELSE m.type
    END as jurisdiction_type,
    COALESCE(m.assessor_url, c.assessor_url) as assessor_url,
    COALESCE(m.tax_collector_url, c.tax_collector_url) as tax_collector_url,
    COALESCE(m.gis_url, c.gis_url) as gis_url,
    COALESCE(m.phone, c.phone) as phone
FROM states s
LEFT JOIN counties c ON c.state_id = s.id
LEFT JOIN municipalities m ON m.state_id = s.id AND (m.county_id = c.id OR m.county_id IS NULL);
```

- Pre-populate municipalities for CT, MA, NJ, NY, PA, NH, VT, ME, RI
